🎯 Création automatique de poules

Cette fonctionnalité va créer des poules équilibrées en tenant compte des horaires préférés des équipes.

❓ Aide - Éditeur de Poules

🎯 Fonctionnalités principales

  • Glisser-déposer : Déplacez les équipes entre les poules ou vers la zone "Non assignées"
  • Double-clic : Modifiez rapidement une équipe ou une poule
  • Filtres : Filtrez par institution, horaire ou niveau
  • Historique : Annulez ou rétablissez vos actions

📊 Statistiques

  • Nombre de matchs : Calculé automatiquement (n*(n-1)/2 pour classique, n*(n-1) pour aller-retour)
  • Horaires : L'horaire d'un match est le plus tardif des deux équipes

🏫 Couleurs des institutions

Chaque institution a une couleur unique pour visualiser rapidement la diversité des poules.

⌨️ Raccourcis clavier

  • Ctrl + Z : Annuler
  • Ctrl + Y : Rétablir
  • Ctrl + S : Exporter
  • Esc : Fermer les modales
